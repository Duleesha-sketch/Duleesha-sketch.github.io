# Our 10th Anniversary ❤️

Open `index.html` in a browser. The 34 photos in `Photos` appear automatically in the backgrounds: 17 on the first page and 17 on the second. Keep the `Photos` folder beside `index.html` when copying or hosting the website.

## Personalize
1. Click **✦ Edit**.
2. Replace the sample messages with your own.
3. Add up to 18 photos for each chapter, counting the included background photos. New selections append to the existing photos. The opening uses a scattered photo background; later chapters use loose collages.
4. Click **Save Changes**.
5. The text/photos are stored in that browser using localStorage.

## Music
Put your own legally obtained MP3 file beside `index.html` and name it `music.mp3`, then use the **♫ Music** button.

## Important
Personalized text and photos stay in your browser; copying index.html does not include them. The edit button is intentionally included for you while preparing it. For a final public version, the Edit button can be removed from the HTML.


## Downloadable letter
Place your letter PDF beside index.html and name it letter.pdf. The final screen includes a Download link for this file. Include letter.pdf when copying or hosting the website.
